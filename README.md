## What is Cupcakes OS?

Cupcakes OS is a Linux distribution based on NixOS.

It keeps the good parts of NixOS — rollback support, reproducible systems, and powerful configuration — while making the experience easier with better defaults, desktop options, installer work, and Cupcakes OS tooling.

Cupcakes OS is built for people who want a powerful Linux system without fighting the system from the start.

---

## Release Lines

### Stable

Stable is for regular installs and daily use.

It uses normal version numbers like:

```txt
2.5
3.0
3.14
4.0
```

Stable gets tested changes and is the safer choice for most users.

## Main Features

- NixOS base
- Rollback-friendly updates
- Multiple desktop options
- ANIX tooling
- Stable release lines
- Custom installer work
- Cupcakes OS-specific defaults and cleanup

---

## ANIX

ANIX is Cupcakes OS’s easier layer for common Nix-style system tasks.

```bash
anix update
anix switch
anix rollback
anix status
```

> [!NOTE]
> ANIX is meant to make Cupcakes OS easier to manage, not hide how the system works.
